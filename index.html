Features

Invoice Management

Create, edit, and send invoices. Templates are simple to customize and integrate with your email or webhook flows.

Client and Product Catalog

Organize clients, store product/service items, and reuse line items across invoices for faster billing.

Payment Integrations

Webhooks and adapters let you connect to payment providers or record offline payments easily.

API Friendly

Designed for developers: clear endpoints, sample scripts, and straightforward data models for automation.

Why Choose Billing Core

Control and Privacy

Self host to keep customer and financial data under your control. No vendor lock‑in.

Lightweight and Fast

Minimal dependencies and a small codebase make it easy to deploy and maintain.

Customizable

Open source code means you can adapt templates, workflows, and integrations to your needs.

Developer Friendly

Clear structure and examples let teams integrate billing into existing systems quickly.

Quick Demo and Usage

Clone the repo, follow the README, and you’ll have a working billing core in minutes.

git clone https://github.com/Halftec/BillingCore.git
cd BillingCore
# follow the repository README for setup steps (install dependencies, configure DB, run migrations)

Integration Tips

  • Use the API endpoints to create invoices programmatically.
  • Hook payment provider webhooks to update invoice status automatically.
  • Customize invoice templates in the templates folder to match your brand.
